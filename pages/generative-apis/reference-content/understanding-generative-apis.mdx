Generative APIs provide serverless access to popular artificial intelligence models through simple API calls. If you are new to generative AI technology, this page will help you understand what Generative APIs are, how they work, and how you can use them in your applications.

## What are Generative APIs?

Generative APIs are application programming interfaces that allow you to interact with advanced AI models programmatically. Instead of downloading, configuring, and hosting complex AI models yourself, you send requests to pre-configured endpoints that return AI-generated responses instantly.

Think of Generative APIs as a conversation with an AI assistant through code. You provide input (called a prompt), and the API returns intelligent output based on that input. This could be generated text, image analysis, audio transcription, or semantic understanding of your data.

## How Generative APIs differ from traditional APIs

Traditional APIs typically perform predefined, deterministic operations such as retrieving data from a database or performing calculations. Generative APIs, however, use machine learning models to create new content or derive meaning from unstructured data. Each response is generated dynamically based on the context you provide, making them ideal for tasks requiring understanding, creativity, or complex pattern recognition.

## Common use cases for Generative APIs

Generative APIs enable a wide range of AI-powered applications across industries:
- **Content generation**: Create articles, product descriptions, marketing copy, or creative writing
- **Conversational agents**: Build chatbots and virtual assistants that understand and respond naturally
- **Document analysis**: Extract insights from documents, summarize lengthy texts, or analyze contracts
- **Code assistance**: Generate, explain, or debug code in multiple programming languages
- **Semantic search**: Build search systems that understand meaning rather than just matching keywords
- **Data enrichment**: Classify, categorize, or extract structured information from unstructured data
- **Multimodal applications**: Analyze images combined with text, or transcribe and analyze audio content

## How to get started

### Prerequisites

To use Scaleway Generative APIs, you need:
- A Scaleway account
- A Scaleway API key with appropriate IAM permissions

If you do not have these, create an account on the Scaleway console and generate an API key from the Identity and Access Management section.

### Try the web playground

The easiest way to explore Generative APIs is through the web playground available in the Scaleway console. Navigate to **Generative APIs** under the **AI** section to access an interactive interface where you can:
- Select from available AI models.
- Enter prompts and see responses instantly.
- Experiment with different parameters like temperature and token limits.
- Understand how models behave before writing code.

This hands-on experience helps you become familiar with how different models respond to various types of prompts.

### Make your first API request

Once you are comfortable with the playground, you can start making programmatic requests. Scaleway Generative APIs accept standard HTTP requests and return JSON responses.

A typical request includes:

- a prompt  
- the model name  
- optional parameters such as  
  - `temperature` (creativity)  
  - `max_tokens` (response length)  
  - system instructions (model behavior)

### Choose the right model

Different models excel at different tasks. When selecting a model:
- Check the [model catalog](/generative-apis/reference-content/supported-models/) in the Scaleway documentation to see available options.
- Consider the model's context window (how much text it can process at once).
- Review token pricing for each model to optimize costs.
- Test multiple models to find the best balance of quality, speed, and cost for your use case.

### Understand tokens and pricing

Tokens are the fundamental units that AI models process. Depending on the language and complexity:

- A token is roughly equivalent to 4 characters in English.
- One word typically equals 1-2 tokens.
- Both your input (prompt) and the model's output (response) consume tokens.

Your usage is measured in total tokens processed (input plus output), and you are billed per million tokens. The Scaleway console displays token consumption for each request, helping you monitor and optimize costs.
